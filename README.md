# 如果由你建國｜政府制度配對測驗

高中公民課程的互動活動。以九道制度選擇，探索與十二個國家政府安排的相似程度，涵蓋行政團隊形成、行政立法制衡、人民提案、中央地方分權與國會選舉。

## 使用方式

下載此儲存庫的 ZIP 並解壓縮，以瀏覽器開啟 `index.html` 即可使用，不需安裝套件或連線後端。

也可在檔案目錄執行：

```sh
python -m http.server 8000
```

接著開啟 `http://localhost:8000`。

## 修改與重建

- `quiz-data.json`：題目、各國特徵、配對規則與資料來源。
- `app.js`：作答、確認答案與結果呈現。
- `engine.js`：配對計分。
- `style.css`：版面與大字閱讀樣式。
- `build.py`：將以上檔案組合成可獨立使用的 `index.html`，只需 Python 3 標準函式庫。

```sh
python build.py
```

## 課堂定位

本活動適合作為引起動機，配對百分比來自透明的教學設定，並非經量表驗證的政治偏好診斷。各國制度存在例外，請搭配課本與各題解析討論。

資料查核：2026年10月。題目共九題，國家共十二國。來源連結列於資料檔內。

學生答案使用瀏覽器分頁的 sessionStorage 暫存，沒有上傳姓名或答案的後端服務。

各國制度資料的原始來源及權利歸其原權利人。此儲存庫未包含課本投影片、第三方文章全文、部署憑證或私人平台設定，亦未另行指定開源授權條款。
