# 如果由你建國｜政府制度配對測驗

公民課教內閣制、總統制時的引起動機活動：6 題、每題 3 個選項，約 3 分鐘。

題目涵蓋行政權歸屬、元首產生、倒閣、解散國會、否決與覆議、議員兼任部長。結果以「內閣制派／總統制派／混合制派」大色卡呈現，學生可舉起手機讓全班看分布，並顯示最接近的國家（英、德、美、韓、法、臺 6 國之一）與相似百分比。

## 使用方式

下載此儲存庫的 ZIP 並解壓縮，以瀏覽器開啟 `index.html` 即可使用，不需安裝套件或連線後端。

也可在檔案目錄執行：

```sh
python -m http.server 8000
```

接著開啟 `http://localhost:8000`。

## 修改與重建

- `quiz-data.json`：題目、各國特徵、配對規則與資料來源；`systems` 設定三種制度的顏色、說明與「想一想」問題。
- `app.js`：作答、確認答案與結果呈現。
- `engine.js`：配對計分。
- `style.css`：版面與大字閱讀樣式。
- `build.py`：將以上檔案組合成可獨立使用的 `index.html`，只需 Python 3 標準函式庫。

```sh
python build.py
```

## 課堂定位

本活動適合作為引起動機，配對百分比來自透明的教學設定，並非經量表驗證的政治偏好診斷。各國制度存在例外，請搭配課本與各題解析討論。

資料查核：2026年10月。共六題、六國。來源連結列於資料檔內。

學生答案使用瀏覽器分頁的 sessionStorage 暫存，沒有上傳姓名或答案的後端服務。
